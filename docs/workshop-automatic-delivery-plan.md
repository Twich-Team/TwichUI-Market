## Decision

1. Add an authenticated, bounded summary protocol with its own format/version. Reuse current canonical snapshot derivation and bridge reference assembly. Deliver all current observed exact variants within explicit caps; do not transmit raw auctions or construct a mandatory SQLite history archive. Preserve asking-price/source semantics, reference coverage, unknown/unsupported states and full selected market identity. Cold derivations are bounded and resumable; immutable export cache uses existing infrastructure. Never hold the collector ingest lock while projecting or downloading.
2. Reuse U1 modulo-64 routing, content pins, canonical tuple semantics and adversarial evidence. The production-candidate contract explicitly extends references with historical value and is distinct from inactive U1 and detailed schema 3. Enforce per-part/aggregate/count limits and whole-generation refusal on overflow, with no silent item truncation. Stable source clocks avoid time-only rewrites.
3. Reuse the native authenticated worker/schedule and filesystem protection helpers. Replace normal delivery setup with Installation, Market, Status, Last update and one Connect/Retry action. Existing archive/scoped diagnostics remain independent and disclosed. Remember one authorized destination; discover bounded registry/common candidates, verify executable edition/build and Workshop capability, and use a native Windows folder picker when needed. Multiple candidates require one choice.
4. Publish a small root manifest and bounded load-on-demand partition addons using the existing fixed-file/atomic replacement pattern. Alternate two owned banks; verify all staged bytes before switching the root commit point, retaining previous root/bank. Never write while WoW runs. Legacy exports remain readable, unowned/incompatible folders refuse, and original SavedVariables are never touched.
5. The Lua reader validates a pinned manifest and requested partitions cooperatively, retains bounded raw bytes/decoded state, and exposes separate external research evidence through existing Bridge/ServerMarket presentation. No invented history or local competition, advice or default changes. U2 supplies refusal semantics, not native identity mappings: exact native-link equivalence remains unsupported; no base-item fallback.
