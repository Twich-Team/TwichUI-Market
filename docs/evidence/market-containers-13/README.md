# Permanent selected verification receipts

These are intentionally retained measurements, not temporary generated fixtures
or installed data. All inputs are public synthetic data; there are no Market
records, tokens, credentials, installers or addon data archives here.

* `session.json`: three measurements after one discarded warm-up per case;
  actual file-backed native publication and production reader/Opportunities,
  120/1,000/5,000 recipes, identical16,384-row/60-day source across193/13 layouts.
* `ui-reopen.json`: three measurements after warm-up of the actual Workshop
  rendering handlers in the recording mock,120 recipes and five reopen/drain
  cycles. It does not reproduce native rendering/frame scheduling.
* `api.json`: selected authenticated synthetic HTTP→production native
  publisher→production Lua integration receipt,129 variants/all64 histories.
  Temporary paths/authentication material are omitted.
* `verification.json`: exact tested sources, hosted links and preserved failed
  attempts. A failed source guard is never treated as certification.

The benchmark JSON retains full measured numbers/ranges and source-file hashes.
Both accepted campaigns passed their source-unchanged and complete economic
oracle checks. They use host system zlib/OpenSSL, never simulator codec stubs.
Native buffers, real frame times and full Forever acceptance are unmeasured.
