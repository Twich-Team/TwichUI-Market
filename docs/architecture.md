# Architecture

One FastAPI service owns versioned REST endpoints, authorization and PostgreSQL transactions. A separate process from the same Python package schedules upstream collection. A small independently scheduled process records bounded hourly PostgreSQL allocation measurements, including when collection is disabled. PostgreSQL stores identities, observations, valuations, security events and sync changes. React/Vite serves the private research application through Caddy. Only Caddy binds to localhost; PostgreSQL remains on an internal Compose network. Tauri consumes data-only versioned sync contracts and exports outside live SavedVariables.

Market identity includes game, region, ruleset, auction house and source kind. Do not merge rulesets or houses merely because observed payloads match. Preserve response hashes, retrieval timestamps, upstream modification timestamps and source namespace. Auction disappearance is not proof of sale.

Initial limits: database 768 MiB/1 CPU, API 384 MiB/0.5 CPU, worker 384 MiB/0.5 CPU, proxy 128 MiB/0.25 CPU, storage monitor 128 MiB/0.25 CPU. Rotated logs, bounded response size and collection concurrency one. Validate enforcement on this rootless host before deployment claims.

Item modernization (active): an additive catalogue surface will query compact per-snapshot statistics with batched daily references and explicit parent/variant separation. Rich metadata/media keep independent provenance and cache status. The browser will use TanStack Query/Table, conditional Virtual, Apache ECharts and Base UI while preserving the existing React/Vite/Docker deployment. See item-modernization-plan.md for acceptance and privacy constraints.

Rich metadata stores validated base-item facts and the resolved Forever namespace separately from auction variants. ItemMedia is an independent bounded local raster cache (32 KiB per asset, 32 MiB total); metadata and artwork can succeed independently. Only public raster bytes use private browser HTTP caching; authenticated business responses remain no-store. View-priority requests only enqueue currently observed item IDs. The optional attributed community source remains beta-scoped, preserves primary fields and never contributes pricing. See item-metadata-providers.md.

Chart history uses daily observations with a 60-day priming window and O(n) rolling references. Full v1 history retains provenance; `view=chart` selects only chart values and provenance flags, with exact money strings. Distribution queries aggregate every current variant listing into at most 32 bands and retain separate bid-only totals. Catalogue variant expansion can require the displayed snapshot ID and fails with 409 if collection advances. See item-experience-scale.json for isolated query plans and bounded scale measurements.

The private website uses TanStack Query with account/role cache clearing and stale-session 401 protection, Table for server-paged item groups and client-paged management records, Base UI for persistent accessible item popovers/column menus, and ECharts for daily history and full-listing distributions. Authenticated pages and the chart engine are lazy imports; charts load near the viewport or through an explicit button. Official artwork loads only near visible clipped rows. Catalogue pages are 25/50/100 groups; long daily data offers virtual scrolling with a native 50-row alternative. No private server state is persisted in localStorage/service workers. Caddy compresses public static assets only; API responses retain the existing no-store/security behavior.

Production ingress and review now use the same backend code in three bounded API configurations, sharing one database/collector: public origin market.twich.gg with authenticated ingress metadata; retained local origin18443 with local legacy-session compatibility; read-only preview origin18444 with its own cookie. Migration0010 binds browser credentials to the issuing origin, leaving device tokens unchanged. Uvicorn does not globally trust forwarded headers. Rootless publishing currently obscures the real network peer, so public HTTP ingress fails closed until administrator source restriction is installed; no forwarding-header substitute is accepted. Details: traefik-preview-operations.md.
