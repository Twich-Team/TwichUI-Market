## Recovery behavior

The existing worker now selects an item goal across eligible providers: current missing names, missing local artwork, applicable essentials, useful equipment details, then justified source refresh. A persisted 20-turn cursor reserves maintenance turns. Candidates are bounded to 64, local decision reconciliation to 32 items/minute, and historical selection to once per 15 minutes. Existing advisory locks, committed leases, persistent jobs and shared quota reservations remain.

Capabilities follow actual adapters. Everloot name cards supply names, not bulk attributes; TheWoWDB supplies its normalized name/quality/level/requirements/vendor/tooltip/artwork fields, without invented class/slot capabilities. ForeverDB handles rich equipment details. Blizzard remains field-authoritative. Unknown classification does not imply equipment; an empty optional field in verified details does not create an endless gap.

Each source retains previous outcomes, fields returned/newly filled/changed, current goals and eligibility explanations. Goal-specific unproductive 200/304 results wait seven days; existing positive freshness windows, 404 caches, errors, authorization, Retry-After and shared cooldowns remain. Verified mapping/build upgrades can justify revisiting successful records. Historical decisions are not fabricated. Before I/O, queued jobs recheck remaining goals and skip redundant work while retaining useful independent work. Deliberate manual refresh is explicit and remains quota/cache controlled.

Artwork first uses eligible stored allowlisted references, preserves valid cached bytes on failure, and never substitutes lower-confidence supplemental art for a working primary icon. Independent image leases, MIME/byte/dimension limits, URL allowlists and local-only website artwork URLs remain.

The administration Tracker provides current-market counts, server filters/sort/pages, compact provider emblems and visible status labels, responsive cards, provenance/journey, actual next-action reasons, persistent manual jobs, and selectable forward-ledger efficiency with a textual chart alternative. Viewing it makes no provider calls. Queued/deferred jobs, uncertain crash reservations, validation, metadata lookups and image downloads are distinguished.
