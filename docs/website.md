# Private React website

The owner-approved React/TypeScript/Vite website is live at **https://market.twich.gg**, application release c8f03c2. [Current production acceptance, tests and rollback](production-promotion-acceptance.md). It uses the authenticated versioned API; no illustrative market values are shipped in application state. Separate /design mockups remain explicitly illustrative. The obsolete approval-pending banner has been removed. Earlier implementation records below are historical.

Working flows: invite-only registration, sign in/out, CSRF recovery after reload, metadata-backed name/ID/variant research (including historical fallback), 7/14/60/365 day chart ranges, current supply/distribution/listings, market comparison, below-reference listings, supply/price-change signals, confidence/coverage/direction filters, users/roles, invitations/revocation, disabled mappings/schedules, collection checks, metadata failures, storage/backup monitoring, connected devices/revocation, security events and password changes that revoke credentials. Missing names retain item-ID fallback; live metadata verification remains a task.

Three real Playwright/PostgreSQL end-to-end workflows pass with isolated synthetic fixtures. Tests cover research/history/comparison/precision, filters/item inspection, invitation acceptance, member/admin permissions, device token sync/revocation, password changes, role changes, disabled mapping creation/schedule guards, storage/security views and mobile document overflow. The first run caught a redeemed-invitation URL reopening registration after sign-out; URL cleanup repaired it, and the clean rerun passed all three tests. Screenshots of the actual React/API pages were visually inspected at 1440×1100 in artifacts/react. These are synthetic-data review screenshots, not live Blizzard observations.

Build/type checks and two Vitest money-format regressions pass, including values beyond JavaScript's exact integer range. Production npm audit reports zero known vulnerabilities. Caddy packages Vite's static output and proxies private API calls. CSP disallows external scripts and framing; invitation referrers are suppressed.

Reproduce: build project images, start `docker --context rootless compose -p twichui-market-browser -f compose.yaml -f compose.browser.yaml up -d`, seed with `... run --rm -T --no-deps api python - < web/e2e/seed.py`, then run the matching Playwright 1.65.1 container on twichui-market-browser_default with repository mounted at /work and working directory /work/web, invoking `npm run test:e2e`. The browser project exposes no host ports and uses a disposable PostgreSQL tmpfs. Always use its separate project name and clean it up with the same compose arguments plus down. CI automates this sequence.
