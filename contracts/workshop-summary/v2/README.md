# Workshop history contract 2

Opt-in `GET /api/v1/workshop/markets/{id}/summary?contract_version=2`. Default version 1 and its generation/parts remain supported. The same authenticated origin/account/market and integrity checks apply. The installed addon must declare `summary_history_contract: 2`, 1,048,576-byte parts and 67,108,864 total bytes; an older addon continues receiving contract 1. No full raw archive is required.

Contract 2 retains the first thirteen version-1 row fields and adds `daily`. The manifest has one chronologically ordered, unique, complete UTC closing observation per available day within the most recent sixty UTC dates. Each observation retains its exact ID, timestamp, completeness and synthetic flag. The final observation binds the current source. Each row has exactly one daily tuple per manifest observation: `[state, recent_copper, minimum_copper, supply]`. States 0–4 mean priced, supply-only, observed absent, unknown and unsupported. Money remains an exact positive decimal string or null; absence is explicit zero supply, unknown/unsupported are null. No synthetic points, interpolation, item-ID identity collapse, silent truncation, completed sales or local-competition claims.

Both producer and native/Lua readers validate bounds, version, canonical encoding, source identity, dates, row ordering/routing, hashes and evidence states. Native delivery uses two fixed owned banks and commits the root after readback. Updating while WoW is open is permitted; the in-memory reader remains pinned until the player reloads. A late partition from an overwritten bank is rejected against its pinned hash, and the reader displays a reload message while retaining validated data. A successful file write is never proof of game consumption. New-addon discovery and actual Forever reload/frame/GC behavior require native acceptance.

The 64-part/64-MiB generation limit bounds retained raw strings; only one partition remains decoded, and validation is cooperative. This ceiling is not a measured memory or frame-time claim. Full-catalogue research explicitly loads more data; automatic research starts with the visible inventory scope. Companion and local scan sources remain distinct, and local scans work without Companion.

`fixtures/synthetic.json` is built with the production sealer by `scripts/build-workshop-history-fixture.py` and mirrored in the paired addon. It is an explicitly synthetic cross-language fixture, not live evidence.
